# Ray Tracer
Ray tracer - Windows x64

## Overview
A ray tracer is a program designed to most accurately capture and simulate real-life environments using computer intensive mathematics. They exist so that people can 
simulate how light physically travels in a 3d environment. Furthermore, ray tracing capabilities of capturing incredibly realistic graphics has made it focal point of interest
within the gaming industry, however, due to the intensity of it, only micro implementation are realistically implemented in most applications.
